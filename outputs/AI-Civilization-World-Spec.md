[Open the canonical design specification](<C:/Users/REY MICHAEL PAMADO/Documents/Codex/2026-09-21/i-x20/docs/superpowers/specs/2026-09-21-ai-civilization-world-design.md>)

The approved design defines:

- four AI-led civilizations with 32 founders each;
- OpenAI, Claude, one same-PC local model, and one local model hosted on a second PC;
- a deterministic world engine that alone controls state and outcomes;
- individual lives, families, births, aging, disease, famine, war, and permanent death;
- asymmetric but balance-tested starting regions and technologies;
- exploration-gated discovery and diplomacy through mortal ambassadors;
- decrees plus direct assignments from immortal sovereigns;
- surrender, allegiance transfer, cultural assimilation, extinction, and a final-survivor victory condition;
- persistent sovereign memory, strict model isolation, replayable history, and a creator covenant that prevents intervention after launch;
- a staged build that validates the simulation with scripted sovereigns before using real model calls.

The remote local-model adapter sends only the private sovereign prompt to the second PC and accepts only a structured reply. It supplies no world files, database access, host tools, or administrative capabilities.

Please review the canonical specification and note any changes you want before implementation planning begins.
