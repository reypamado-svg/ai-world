# Treaty Ratification Plan

**Goal:** Make foreign agreements travel-bound and bilateral before trade and migration consume them.

1. Add immutable treaty offers and active treaty records to canonical state.
2. Carry a treaty offer only through an ambassador message to a discovered foreign settlement.
3. Let only the civilization that received that exact offer send an acceptance back along a known route.
4. Activate an agreement only when the acceptance message reaches the original proposer; lost, delayed, or distorted messages never activate it early.
5. Keep offers and received messages private to their participants and replay every outcome deterministically.
